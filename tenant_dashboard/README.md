# 康生通東1丁目17 テナント出店ポテンシャル ダッシュボード

岡崎市のオープンデータ（BODIK）を活用し、対象物件（**康生百貨店／岡崎市康生通東一丁目17**）への
テナント誘致を支援する静的Webダッシュボードです。

「この場所は、いつ・誰が・どちら向きに通り、周辺に何の店があり、どの業種が入りやすいか」を
1つの画面で提案資料として見せられます。

## 画面構成

1. **トップ** … サイト説明・各画面への導線・AIデータアシスタント（デモ）
2. **物件情報** … 立地マップ・主要施設との距離・施設概要・賃料相場（※ダミー）・地価
3. **人流分析** … 期間指定に対応。通行量の推移（日/週/月）＋時間帯／曜日／年代／性別／進行方向＋周辺イベント
4. **周辺店舗・競合** … 業種で色分けした店舗マップ・業種別店舗数・店舗一覧
5. **消費者傾向** … 市民意識調査・市内食品営業種別・康生周辺人口・所得推移
6. **商圏人口** … 徒歩圏人口（町字合算）・世帯構成・将来性・都市計画

### 人流分析画面の使い方
- 上部の**表示期間**（全期間／直近12・6・3か月、または開始月〜終了月のプルダウン）で
  ページ全体（推移・時間帯・曜日・年代・性別・進行方向・イベント）が選択期間で再集計されます。
- 「通行量の推移」は**日/週/月**で粒度を切替。季節性から**出店時期**、曜日差から**営業日・販促曜日**を判断できます。
- **日/週/月**表示では周辺イベントをオレンジ▲で重ね、スパイクとの対応が見えます（点クリックでその期間のイベント一覧）。
- イベント表は開催日の通行量が同曜日中央値からどれだけ増えたか（**押し上げ効果**）で並び、
  「花火大会」「家康行列」などの集客イベントに合わせた**販促・仕入れ計画**の根拠になります。

## データの出典と算出方法

データ生成は `build_data.py` が行い、結果を `data/*.json` と `site/js/data.js` に出力します。

### 人流データ

**出典:** 岡崎市オープンデータ「QURUWA地区の人流データ」(BODIK)

**対象:**
- カメラグループ「康生通り」（カメラID 0〜3）の通過人数（`NoP`）および入場／退場（`Input`／`Output`）
- **2021年1月以降**の月次CSVを使用（2020年分は欠損補間が多いため除外）
- 提供元仕様により、一部期間は中央値補間を含む

**算出方法:**
- 対象カメラの人数を日付単位で合算し、**のべ人数 ÷ 日数**で1日平均通行量を算出
- 時間帯別・曜日別・年代別・性別・カメラ別方向も同様に合計し、表示時は選択期間の日数で平均化
- 日次／週次／月次時系列は、日次合計を週・月で平均したもの
- 画面上の期間指定では、事前に保存した月別内訳（`monthly_breakdown`）と日次系列から再集計

---

### 周辺イベント・押し上げ効果

**出典:** 岡崎市オープンデータ「イベント一覧」(BODIK) ＋上記人流

**対象の絞り込み:**
- 物件から直線距離 **1,500m以内**（緯度経度がある場合）
- または場所名・住所に「康生」「籠田」「りぶら」「岡崎公園」等のキーワードを含むもの

**算出方法:**
- 同一イベント名で開催日を集約
- **押し上げ効果（%）** ＝ `(開催代表日の通行量 ÷ 同曜日の中央値 − 1) × 100`
- 同曜日中央値は、人流日次データから曜日ごとの中央値（`dow_median`）を事前計算したもの
- 代表日は、人流タイムライン期間と重なる開催日のうち最初の日

---

### 周辺店舗・競合

**出典:** 岡崎市オープンデータ「食品等営業許可・届出一覧」(BODIK)  
**座標化:** 国土地理院住所検索API（ジオコーダ）

**算出方法:**
- 住所をジオコードし、物件から直線距離 **400m以内**の店舗を抽出
- 営業種類から飲食系カテゴリ（レストラン・カフェ・居酒屋等）に分類し、件数を集計
- 食品営業許可ベースのため、美容・学習塾・フィットネス等の非食品業種は含まない

---

### 消費者傾向

**出典:**
- 令和6年度市民意識調査 (BODIK) … 年齢・職業・満足度・休日の過ごし方・中心市街地への出没・交通手段など
- 地域・年齢別人口／食品等営業許可 (BODIK) … 康生周辺の人口構成・市内食品営業種別
- 岡崎市統計（市民所得関連xls） … 所得推移・家計所得内訳・産業構成

**算出方法:**
- 意識調査は選択肢コードをラベルに対応づけ、回答数・構成比（%）を集計
- 周辺人口は指定町字の人口・世帯を合算
- 所得・産業は統計表の年度系列を読み取り、最新年度の内訳割合を算出

---

### 商圏人口

**出典:** 岡崎市「地域・年齢別人口」(BODIK)、世帯構成は市民意識調査

**算出方法:**
- **徒歩5分圏相当:** 康生町・康生通・連尺通・籠田町・伝馬通・材木町・本町通 など指定町字の人口・世帯を合算（約400m相当の概算）
- **徒歩10分圏相当:** 上記に松本町・十王町・花崗町等を加えた町字合算（約800m相当の概算）
- 年齢構成は徒歩10分圏の年齢区分を構成比（%）化
- 高齢者比率は徒歩10分圏の65歳以上割合
- 単身比率・世帯類型は意識調査から算出（全市サンプルのため厳密な徒歩圏世帯ではない）
- ※道路ネットワーク距離の徒歩圏ではなく、**町字名による概算**である点に注意

---

### 賃料・地価

**賃料相場:**
- 公開オープンデータが見つからないため **ダミー値**（1階路面・2階以上・本物件想定の円/坪）
- 画面上は「ダミー」と明記

**地価:**
- **出典:** 国土交通省 国土数値情報 地価公示（愛知県）
- **算出:** 岡崎市内（市区町村コード 23202）の標準地のうち、用途は商業地を優先し、物件座標に最も近い地点の公示価格（円/㎡）を採用
- 物件敷地そのものの価格ではなく、最寄り標準地の参考値

---

### 将来性・都市計画／施設概要

**将来性・都市計画:**
- 岡崎市立地適正化計画、国交省コンパクトシティ関連資料、QURUWA・中心市街地整備の公開資料から要点を固定掲載（自動集計ではない）

**施設概要（康生百貨店）:**
- ぽけろーかる等の公開情報をもとに、住所・アクセス・紹介URL・入居店例などをメタデータとして保持
- 座標は国土地理院ジオコーダで「康生通東一丁目17番地」を解決した値

> 人流データは2021年1月以降を使用（2020年分は欠損補間が多いため除外）。2025〜2026年分は一部中央値補間を含みます（提供元仕様）。

## 使い方

### 1. データを生成する

```bash
cd tenant_dashboard
python build_data.py             # 全期間（BODIK公開分すべて）
python build_data.py --months 24 # 直近24か月のみ
python build_data.py --months 12 # 直近12か月（速い）
python build_data.py --refilter-local  # 既存 data/*.json から2020年人流を除外して再生成
python build_data.py --rent-only        # 地価公示だけ取得して rent を更新
```

> 既定は**全期間**（2021年1月〜最新月）。2020年分は欠損補間が多いため除外しています。

`site/js/data.js`（ブラウザ用）と `data/*.json`（参照用）が生成されます。
※初回はネット経由でCSV取得＋住所ジオコードを行うため数分かかります。

必要ライブラリ:

```bash
pip install pandas requests xlrd
```

### 2. ダッシュボードを開く

`site/js/data.js` を同梱しているため、**`site/index.html` をブラウザで開くだけ**で表示できます。

うまく地図/グラフが出ない場合はローカルサーバ経由で開いてください:

```bash
cd tenant_dashboard/site
python -m http.server 8000
# → http://localhost:8000/ をブラウザで開く
```

## カスタマイズ

- 対象物件を変える: `build_data.py` の `BUILDING` を編集
- 対象の通り（カメラ）を変える: `TARGET_CAMERA_GROUP`（例: 連尺通り / 中央緑道）
- 集計半径を変える: `STORE_RADIUS_M`（店舗）、`EVENT_RADIUS_M`（イベント）
- 商圏の町字を変える: `WALK5_AREA_NAMES` / `WALK10_AREA_NAMES`

## 注意

オープンデータのみで正確な売上は算出できません。本ダッシュボードの数値は
「売上ポテンシャル／来店可能性／商圏魅力度」の目安であり、売上予測ではありません。
賃料は公開データがないためダミーであり、本物件の実際の募集条件とは異なります。
