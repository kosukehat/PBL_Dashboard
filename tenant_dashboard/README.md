# 康生通東1丁目16 テナント出店ポテンシャル ダッシュボード

岡崎市のオープンデータ（BODIK）を活用し、対象物件（**岡崎市康生通東一丁目16**）への
テナント誘致を支援する静的Webダッシュボードです。

「この場所は、いつ・誰が・どちら向きに通り、周辺に何の店があり、どの業種が入りやすいか」を
1つの画面で提案資料として見せられます。

## 画面構成（6画面）

1. **物件サマリー** … 立地・QURUWA内の位置・主要施設との距離・KPI・おすすめ業種TOP3
2. **人流分析** … 期間指定に対応。通行量の推移（日/週/月）＋時間帯／曜日／平日休日／年代／性別／進行方向＋周辺イベント
3. **周辺店舗・競合** … 業種で色分けした店舗マップ・業種別店舗数・店舗一覧
4. **消費者傾向** … 市民意識調査（年齢・職業・商業満足度・休日/中心市街地出没）・市内食品営業種別・康生周辺人口・所得推移
5. **商圏人口** … 徒歩圏人口（地域・年齢別人口）・世帯構成（市民意識調査）・賃料相場（※ダミー）・将来性
6. **業種チャンス** … 人流×競合から算出した業種チャンスランキング

### 人流分析画面の使い方
- 上部の**表示期間**（全期間／直近12・6・3か月、または開始月〜終了月のプルダウン）で
  ページ全体（推移・時間帯・曜日・年代・性別・進行方向・イベント）が選択期間で再集計されます。
- 「通行量の推移」は**日/週/月**で粒度を切替。季節性から**出店時期**、曜日差から**営業日・販促曜日**を判断できます。
- **日**表示では周辺イベント開催日をオレンジ▲で重ね、スパイクとの対応が見えます。
- イベント表は開催日の通行量が同曜日中央値からどれだけ増えたか（**押し上げ効果**）で並び、
  「花火大会」「家康行列」などの集客イベントに合わせた**販促・仕入れ計画**の根拠になります。

## データソース

| データ | 出典 | 実/ダミー |
| --- | --- | --- |
| 康生通りの人流（年代・性別・時間・方向・時系列） | 岡崎市「QURUWA地区の人流データ」(BODIK) | 実データ |
| 周辺イベント | 岡崎市「イベント一覧」(BODIK) | 実データ |
| 周辺店舗（飲食系） | 岡崎市「食品等営業許可・届出一覧」(BODIK) + 国土地理院ジオコーダで座標化 | 実データ |
| 消費者傾向（意識調査・人口・所得） | 令和6年度市民意識調査・地域・年齢別人口・人口世帯数(BODIK) + 岡崎市統計(所得) | 実データ |
| 商圏人口・世帯 | 地域・年齢別人口（町字合算）+ 市民意識調査 | 実データ（概算） |
| 賃料相場 | （公開オープンデータなし） | **ダミー** |
| 地価 | 国土交通省 [国土数値情報 地価公示](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-L01-2026.html)（最寄り商業地標準地） | 実データ |
| 将来性・都市計画 | 岡崎市立地適正化計画・QURUWA等（公開資料） | 実データ |

> 人流データは2021年1月以降を使用（2020年分は欠損補間が多いため除外）。2025〜2026年分は一部中央値補間を含みます（提供元仕様）。

## 使い方

### 1. データを生成する

```bash
cd tenant_dashboard
python build_data.py             # 全期間（BODIK公開分すべて）
python build_data.py --months 24 # 直近24か月のみ
python build_data.py --months 12 # 直近12か月（速い）
python build_data.py --refilter-local  # 既存 data/*.json から2020年人流を除外して再生成
python build_data.py --rent-only        # 地価公示だけ取得して rent を更新
```

> 既定は**全期間**（2021年1月〜最新月）。2020年分は欠損補間が多いため除外しています。

`site/js/data.js`（ブラウザ用）と `data/*.json`（参照用）が生成されます。
※初回はネット経由でCSV取得＋住所ジオコードを行うため数分かかります。

必要ライブラリ:

```bash
pip install pandas requests xlrd
```

### 2. ダッシュボードを開く

`site/js/data.js` を同梱しているため、**`site/index.html` をブラウザで開くだけ**で表示できます。

うまく地図/グラフが出ない場合はローカルサーバ経由で開いてください:

```bash
cd tenant_dashboard/site
python -m http.server 8000
# → http://localhost:8000/ をブラウザで開く
```

## カスタマイズ

- 対象物件を変える: `build_data.py` の `BUILDING` を編集
- 対象の通り（カメラ）を変える: `TARGET_CAMERA_GROUP`（例: 連尺通り / 中央緑道）
- 集計半径を変える: `STORE_RADIUS_M`
- スコアの重み・業種: `build_scores()` を編集

## 注意

オープンデータのみで正確な売上は算出できません。本ダッシュボードの数値は
「売上ポテンシャル／来店可能性／業種適合度／商圏魅力度」の目安であり、売上予測ではありません。
